# CLAUDE.md

## Проект

**vladimir-ai-presentation** — статичная персональная презентация на React + Vite для потенциального клиента **Владимира Заморенова**.

Владимир занимается B2B-бизнес-консалтингом: госзаказ, франшизы, недвижимость, стоматология. Целевая аудитория — предприниматели МСБ. Его интересует автоматизация маркетинга, контента, продаж, агентской системы, и личный AI-помощник в Telegram.

Цель презентации — наглядно показать AI-решения для его бизнеса. Это НЕ рабочее приложение, не CRM, без БД/авторизации/API/форм/аналитики — только статичные слайды.

**Важно:** не путать с проектом `krasnodar-remont` в соседней папке — это другой проект другого клиента, его контент и данные сюда не переносить. «Ремонт Про» упоминается в презентации только как один кейс, подтверждающий опыт разработки (слайд 02), без деталей его внутренней архитектуры.

## Формат слайдов

8 слайдов, каждый — строго 1440×900px, без вертикальной прокрутки, тёмная тема, премиальный деловой стиль AI-платформы. Шрифты: Manrope (заголовки) + Inter (текст). Без фото людей, без мелкого текста, без цен/кнопок/форм, без придуманных показателей (проценты роста, число клиентов и т.п.).

Маршруты:
```
/01-cover              — обложка                              ✅ готово
/02-remont-pro          — кейс «Ремонт Про»                     ⬜ ждёт задания
/03-jarvis              — «Джарвис», AI-помощник в Telegram     ⬜ ждёт задания
/04-marketing-content    — автоматизация маркетинга и контента  ⬜ ждёт задания
/05-sales                — автоматизация B2B-продаж             ⬜ ждёт задания
/06-agent-system         — агентская система                    ⬜ ждёт задания
/07-two-levels           — два уровня AI-решений                ⬜ ждёт задания
/08-next-step            — следующий шаг, диагностика           ⬜ ждёт задания
```

`/` редиректит на `/01-cover` (это ссылка для клиента). `/menu` — служебное меню со списком слайдов, только для разработки, клиент его не видит.

## Архитектура

- `src/slides.js` — единый реестр слайдов (путь, номер, заголовок), используется роутером и меню.
- `src/components/Slide.jsx` + `Slide.css` — базовый холст 1440×900 для каждого слайда: номер слайда справа снизу, точки-навигация по центру снизу, стрелки-кликзоны по краям экрана.
- `src/hooks/useSlideNavigation.js` — листание стрелками клавиатуры/пробелом/PageUp-PageDown и кликом.
- `src/pages/slides/*.jsx` + одноимённый `.css` — каждый слайд отдельным компонентом. Паттерн: `<Slide number="0N" className="имя-слайда">...</Slide>`, стили в соседнем CSS-файле.
- Дизайн-токены (цвета, шрифты) — в `src/index.css` (`:root`), переиспользуются как CSS-переменные (`--accent`, `--text-secondary`, `--font-display` и т.п.).

## Как проверяю вёрстку

Средой заблокирован сетевой доступ к localhost по умолчанию — dev-сервер и скриншоты headless-браузером (Playwright, `npx playwright screenshot`) запускаю с флагом отключения песочницы. Уже находил так реальный баг (переопределение фиксированной высоты слайда) — визуальную проверку скриншотом делать обязательно перед тем как отчитываться о готовности слайда.

## Как работаем

Каждый слайд пользователь присылает отдельным заданием (текст заголовков/карточек/структуры). Не придумывать контент за него, не делать все слайды сразу.
